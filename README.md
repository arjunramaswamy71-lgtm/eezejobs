# HedgeMyJob

Scores how exposed a job is to AI, finds the public companies that profit if AI takes over that work, and backtests whether owning them would have offset falling hiring in the field.

Fields so far: finance and accounting, legal, customer service.

Data: Anthropic Economic Index (CC-BY), Indeed Hiring Lab (CC-BY), O*NET, Yahoo Finance.

Educational research tool, not investment advice.

## Setup

```
pip install -r requirements.txt
python download_data.py
```
